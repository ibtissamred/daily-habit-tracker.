# Daily Habit Tracker

## Project Overview
Daily Habit Tracker is a web application developed with Python and Flask that helps users organize their daily habits and monitor their progress.

## Features
- Add and delete habits
- Mark habits as completed or undo completion
- Store habits and daily completion records in an SQLite database
- Display daily completion progress
- View a weekly progress summary with completion percentages

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run
1. Install Python.
2. Install Flask using `python -m pip install flask`.
3. Open a terminal in the project folder.
4. Run `python app.py`.
5. Open `http://127.0.0.1:5000` in your browser.

## Learning Outcomes
This project provided practical experience with web application development, database operations, HTML templates, HTTP routes, and tracking records by date.
